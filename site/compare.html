STRAIGHT TALK

When something else fits better.

  • Proposal drafting, CRM, pipeline management, or bid scoring: the paid platforms above do this; 1102tools does not.
  • State and local opportunities: 1102tools covers federal sources only.
  • One install for dozens of sources: broad local packages such as cliwant/mcp-sam-gov cover more sources, with fewer tools per source.

How this was researched

Researched September 24, 2026. Claude directory status comes from Anthropic's public directory data; ChatGPT directory status comes from searching the public ChatGPT app directory. Prices are quoted from each vendor's public pricing page on that date; tiers change, so check the linked source before buying. Other MCP servers were found through the official MCP Registry, GitHub, Smithery, PulseMCP, and Glama. 1102tools test counts come from pytest --collect-only and include live-gated tests. Competitor tool counts come from their public listings; competitor software and tests were not run.
