LOCAL OR HOSTED

Two ways to run it.

Hosted

Install SAM.gov from the Claude and ChatGPT directories, or add https://sam.1102tools.com/mcp as a custom connector in any AI app that connects to an MCP server by URL. No account or API key, always the latest release, and it works on web, desktop and phone. The hosted edition has 6 tools for searching and reading contract opportunities, award notices, and justifications; looking up public entity registrations by UEI or CAGE and searching by name, NAICS, state, business/SBA certification codes, and active status; checking exclusions by UEI, CAGE, or name.

Local

A free Python package that runs on your own computer and connects straight to SAM.gov, so nothing passes through 1102tools. The full edition needs a free SAM.gov API key. Your AI app can set it up for you from the setup guide.

COMMON QUESTIONS

About the SAM.gov MCP server.

Is the SAM.gov MCP server free?
Yes. It is free and open source under the MIT license, with no account, ads or tracking.
Is it an official government server?
No. 1102tools is independent and built by a federal contracting officer. No federal agency runs an official production MCP server for SAM.gov (checked October 8, 2026).
Do I need an API key?
Not when hosted. For the local version: the full edition needs a free SAM.gov API key.
Which AI apps does it work with?
Claude and ChatGPT through their directories, plus any AI app that connects to a remote MCP server by URL. The local version works with any MCP client, such as Claude Desktop, Claude Code and Codex.
How current is the data?
Hosted: dated public files, with opportunities checked every two hours, exclusions checked every four hours plus an extra check after usual daily publication, and monthly entity registrations checked alongside exclusions. Opted-out entities are not included in the hosted public mirror. Confirm current registration on SAM.gov. Local full edition: live SAM.gov APIs with detailed certification, reps/certs, and integrity fields.
Can anyone see what I search?
No. Searches aren't logged or saved, and IP addresses aren't kept. When the hosted server calls a government site, the request comes from 1102tools, not from you. Your AI app handles the conversation under its own privacy policy.
Can I use it with CUI?
CUI (Controlled Unclassified Information) is a question for your AI app, not for this server. The SAM.gov server only looks up public government data and gets only the search your AI sends, never your chat or files. Whether CUI can go in your chat depends on your AI app and your agency's or company's rules, and it's the same for Local and Hosted.
Who builds it?
A federal contracting officer who has worked in the 1102 contracting series since 2012. Most people who use 1102tools are small businesses, capture and business development teams, proposal writers and consultants.
Where is the privacy notice?
See the SAM.gov server notice and the 1102tools privacy page.
