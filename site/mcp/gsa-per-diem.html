LOCAL OR HOSTED

Two ways to run it.

Hosted

Install GSA Per Diem from the Claude and ChatGPT directories, or add https://gsa-perdiem.1102tools.com/mcp as a custom connector in any AI app that connects to an MCP server by URL. No account or API key, always the latest release, and it works on web, desktop and phone.

Local

A free Python package that runs on your own computer and connects straight to GSA Per Diem, so nothing passes through 1102tools. It needs a free API key only for city names its bundled Census and county data can't place, or years before FY2021. Your AI app can set it up for you from the setup guide.

COMMON QUESTIONS

About the GSA Per Diem MCP server.

Is the GSA Per Diem MCP server free?
Yes. It is free and open source under the MIT license, with no account, ads or tracking.
Is it an official government server?
No. 1102tools is independent and built by a federal contracting officer. No federal agency runs an official production MCP server for GSA Per Diem (checked October 8, 2026).
Do I need an API key?
Not when hosted. For the local version: it needs a free API key only for city names its bundled Census and county data can't place, or years before FY2021.
Which AI apps does it work with?
Claude and ChatGPT through their directories, plus any AI app that connects to a remote MCP server by URL. The local version works with any MCP client, such as Claude Desktop, Claude Code and Codex.
How current is the data?
1102tools' copy of GSA's published per diem files for fiscal years 2021 onward; most city lookups are settled from Census and GSA county data, and other city names, and earlier years, use the live GSA API.
Can anyone see what I search?
No. Searches aren't logged or saved, and IP addresses aren't kept. When the hosted server calls a government site, the request comes from 1102tools, not from you. Your AI app handles the conversation under its own privacy policy.
Who builds it?
A federal contracting officer who has worked in the 1102 contracting series since 2012. Most people who use 1102tools are small businesses, capture and business development teams, proposal writers and consultants.
Where is the privacy notice?
See the GSA Per Diem server notice and the 1102tools privacy page.
