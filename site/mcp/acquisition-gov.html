LOCAL OR HOSTED

Two ways to run it.

Hosted

Install Acquisition.gov from the Claude and ChatGPT directories, or add https://acquisition-gov.1102tools.com/mcp as a custom connector in any AI app that connects to an MCP server by URL. No account or API key, always the latest release, and it works on web, desktop and phone.

Local

A free Python package that runs on your own computer and connects straight to Acquisition.gov, so nothing passes through 1102tools. No API key needed. Your AI app can set it up for you from the setup guide.

COMMON QUESTIONS

About the Acquisition.gov MCP server.

Is the Acquisition.gov MCP server free?
Yes. It is free and open source under the MIT license, with no account, ads or tracking.
Is it an official government server?
No. 1102tools is independent and built by a federal contracting officer. No federal agency runs an official production MCP server for Acquisition.gov (checked October 8, 2026).
Do I need an API key?
Not when hosted. For the local version: no API key needed.
Which AI apps does it work with?
Claude and ChatGPT through their directories, plus any AI app that connects to a remote MCP server by URL. The local version works with any MCP client, such as Claude Desktop, Claude Code and Codex.
How current is the data?
A copy of Acquisition.gov's FAR Overhaul text and agency deviations, refreshed daily.
Can anyone see what I search?
No. Searches aren't logged or saved, and IP addresses aren't kept. When the hosted server calls a government site, the request comes from 1102tools, not from you. Your AI app handles the conversation under its own privacy policy.
Can I use it with CUI?
It depends on your AI, not the server. The Acquisition.gov server only reads public government data. Locally, lookups go straight from your computer to the source and nothing reaches 1102tools. Hosted, only the lookup your AI sends (like a NAICS code or vendor name) reaches the server, never your chat or files, and searches aren't logged. Whether CUI (Controlled Unclassified Information) can go in your chat depends on the AI you use and your agency's or company's rules.
Who builds it?
A federal contracting officer who has worked in the 1102 contracting series since 2012. Most people who use 1102tools are small businesses, capture and business development teams, proposal writers and consultants.
Where is the privacy notice?
See the Acquisition.gov server notice and the 1102tools privacy page.
