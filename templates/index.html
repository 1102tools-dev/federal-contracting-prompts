HOW EVERY SERVER IS TESTED

  • Checked against the sourceRealistic contracting questions run against each server, and the answers are compared with the government source: the numbers, the dates, the citations.
  • Worst problems firstEvery problem is ranked by how much it could mislead you, from a wrong answer you might act on down to a minor wording issue. Wrong answers are fixed first.
  • Reviewed by more than one AIAudits run with both Claude Code and Codex, and every finding is checked by a second reviewer before a fix ships.
  • Fixed for goodEvery fix gets a test so the problem can't come back, and thousands of these tests run before each release. See the testing records on GitHub ↗
